# Gokul Portfolio — V2

Premium single-page developer portfolio built with vanilla HTML, CSS and JavaScript.

## Included
- Responsive layout
- Dark/light theme toggle with localStorage
- Mobile navigation
- Scroll-reveal animations
- Project filters
- Recruiter-focused information hierarchy
- Accessible labels and semantic sections
- No backend required

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Before publishing
Replace:
- `assets/Gokul_Resume.pdf`
- `your.email@example.com`
- LinkedIn URL
- GitHub URL
- Next project placeholder content
- Any education/internship details you want shown

## Deploy
Upload the folder to GitHub and connect the repository to Vercel or Netlify.
